# Third-party data in this folder

`font-categories.json` and the curated pairings in `pairings.json` come from UI UX Pro Max (https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) and taste-skill (https://github.com/Leonxlnx/taste-skill), under the licences below.

The other pairings are generated by `build-data.mjs` from web-typography's pairing rules, using font facts (names, categories, weights, designers, licences) from these catalogues:

- Google Fonts metadata, via UI UX Pro Max (MIT, below).
- Fontshare, by Indian Type Foundry (https://www.fontshare.com, https://api.fontshare.com/v2/fonts). Its fonts are free for personal and commercial use under the ITF Free Font License (https://www.fontshare.com/licenses/itf-ffl), or the SIL Open Font License for some.
- Fontsource (https://fontsource.org, https://api.fontsource.org/v1/fonts): open-source fonts that aren't on Google Fonts, mostly under the SIL Open Font License; each pairing records its fonts' licence.
- Modern Font Stacks (https://github.com/system-fonts/modern-font-stacks), dedicated to the public domain under CC0 1.0. The system font stacks are copied from it.

No font files are included here: the page loads them from Google Fonts, Fontshare's CDN or jsDelivr, or uses fonts already on the device.
